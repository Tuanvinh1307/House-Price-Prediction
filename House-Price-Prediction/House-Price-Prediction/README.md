# House Price Prediction

Predict the sale price of houses using the Kaggle "Home Data for ML Course" (Ames Housing) dataset.

## Contents
- `House_Price_Prediction_Project.ipynb` – notebook: feature selection, train/validation split, Decision Tree and Random Forest regressors.
- `data/` – `train.csv`, `test.csv`, `sample_submission.csv`, `data_description.txt`.

## Features used
`LotArea`, `YearBuilt`, `1stFlrSF`, `2ndFlrSF`, `FullBath`, `BedroomAbvGr`, `TotRmsAbvGrd`

## Run
Update the data path in the notebook to `data/train.csv` (it currently uses `/content/train.csv` from Colab), then run all cells.
